# MOC Restaurant

A configurable QBCore restaurant framework for FiveM.

**Current stable release: v3.3.6**

MOC Restaurant includes in-game restaurant creation, POS ordering, business management,
employee/rank/payroll tools, deliveries and restocking, restaurant-specific menus and
recipes, kitchen production, storage, drive-thru systems, custom restaurant blips, and
configurable station placement.

## Repository Layout

- `moc_restaurant/` — current stable FiveM resource
- `Fix Notes/` — complete version-by-version history
- `CHANGELOG.md` — condensed release history
- `INSTALLATION.md` — installation guidance
- `UPGRADING.md` — safe upgrade workflow

## Installation

See [INSTALLATION.md](INSTALLATION.md).

## Releases

Each GitHub release should use the matching prepared asset from the companion
`release_assets` folder. Every release asset contains its resource plus cumulative
`Fix Notes`.
