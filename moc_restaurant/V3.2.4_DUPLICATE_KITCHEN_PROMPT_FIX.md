# MOC Restaurant v3.2.4 - Duplicate Kitchen Prompt Fix

Fixes seeing two different [E] prompts while standing at:
- Grill
- Fryer
- Prep Station
- Drink Station

Cause:
The old `client/kitchen.lua` interaction loop and the newer
`client/production.lua` interaction loop were both active.

Fix:
The legacy kitchen interaction thread is disabled.
The restaurant-specific production system is now the only interaction system
for kitchen production stations.

Expected result:
Standing at a Grill should show only one prompt:
`Press E to use Grill`

No SQL update is required from v3.2.3 to v3.2.4.
