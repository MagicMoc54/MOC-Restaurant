# MOC Restaurant v3.3.3 - POS Delete Sync Fix

This update fixes a Menu Management item remaining on the POS after it is removed.

The Menu Management delete action now:
1. Deletes the restaurant-specific row from `moc_restaurant_menu_items`.
2. Scopes the deletion to the correct restaurant.
3. Uses the menu item's database ID when available.
4. Broadcasts a POS-menu refresh notification.
5. Shows "Menu item removed and POS updated." when successful.

Because the POS in v3.3.2 reads its menu live from `moc_restaurant_menu_items`,
the removed item will no longer be returned the next time the POS opens.

No SQL update is required from v3.3.2.
