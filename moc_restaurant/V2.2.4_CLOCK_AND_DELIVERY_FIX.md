# MOC Restaurant v2.2.4

Fixes both issues reported during v2.2 testing.

## Clock In / Clock Out

oxmysql can return a TINYINT/BOOLEAN column as Lua `true` / `false`.

The previous verification expected numeric `1` / `0`, causing:
`Expected 1, got true`

v2.2.4 normalizes:
- true -> 1
- false -> 0
- numeric/string 1/0 -> corresponding number

So a successful clock-in is no longer incorrectly rejected.

## Deliveries Callback

The separate delivery server module was not registering on the live server.

v2.2.4 moves all delivery server callbacks/events into:
`server/business.lua`

That file is already proven to execute because Business Management is working.

After restart, txAdmin should print:
`[MOC Restaurant] v2.2.4 delivery callbacks registered inside business.lua.`

The callback:
`moc_restaurant:getDeliveryCatalog`

should therefore exist whenever Business Management exists.

## SQL

No new SQL is required from v2.2.3 to v2.2.4.
You still need the earlier v2.2.1 SQL columns `ready_at` and `delivered_at`.
