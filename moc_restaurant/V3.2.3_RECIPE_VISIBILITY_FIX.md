# MOC Restaurant v3.2.3 - Kitchen Recipe Visibility Fix

Fixes restaurant-specific recipes not appearing at the physical kitchen station.

Changes:
- Recipe visibility is no longer blocked by clock/permission validation.
- Recipes always display for the correct restaurant + station.
- Off-duty employees can see recipes but cannot select/craft them.
- Crafting remains server-authorized and still requires clock-in when configured.
- `drink` / `drinks` station naming is normalized.
- Server and F8 diagnostics now print recipe counts.

Diagnostic:
`mocrecipecheck`

Stand next to the Grill and run it. It prints:
- restaurant ID
- station type
- number of recipes returned
- every returned recipe

No SQL update is required from v3.2.2 to v3.2.3.
