# MOC Restaurant v1.5.5 - Per-Station Interaction Radius

This update prevents nearby restaurant stations from fighting over the E interaction.

## New behavior
When placing a location through:
`/mocrestaurant -> Open Builder -> Place Location`

you now choose an Interaction Radius.

Recommended:
- Register: 0.50 - 0.65
- Grill: 0.50 - 0.65
- Fryer: 0.50 - 0.65
- Drink Station: 0.50 - 0.65
- Prep Station: 0.50 - 0.65
- Storage / Freezer: 0.65 - 0.85
- Drive-Thru Speaker: 1.5 - 2.5

Default radius is now 0.65.

## Existing stations
Run:
`sql/upgrade_v1.5.4_to_v1.5.5.sql`

Existing stations will default to radius 0.65.

## Future editing
The radius is stored per location in SQL, so a later builder update can expose
Edit Radius / Move Station without replacing the location.
