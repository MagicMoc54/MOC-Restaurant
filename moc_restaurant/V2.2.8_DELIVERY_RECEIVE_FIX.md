# MOC Restaurant v2.2.8 - Delivery Receive Fix

Fixes READY deliveries doing nothing when clicked.

## New receive flow

Click READY Delivery
-> client prints selection
-> "Preparing delivery #..." notification
-> explicit server receive request
-> server validates:
   - delivery exists
   - delivery status is READY
   - employee has permission
   - player is near the correct Delivery Receiving station
   - shipment item data is valid
-> server adds each item
-> database changes delivery to DELIVERED
-> client receives success confirmation

## Diagnostics

Client F8:
[MOC Restaurant] READY delivery #X selected.

Server console:
[MOC Restaurant] Receive delivery request...
[MOC Restaurant] Delivery #X status=ready...
[MOC Restaurant] Adding delivery item...
[MOC Restaurant] Delivery #X successfully received.

If anything fails, the player now gets a visible error notification rather than
nothing happening.

No SQL update is required from v2.2.7 to v2.2.8.
