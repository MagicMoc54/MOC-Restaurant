# MOC Restaurant v3.3.0 - Custom Restaurant Blips

Built directly on the stable v3.2.4 branch.

Carries forward:
- Working explicit Clock In / Clock Out
- Business Management
- Automatic QBCore/qb-banking setup
- Deliveries & Restocking
- Delivery Receiving
- Restaurant-specific menu management
- Restaurant-specific kitchen recipes
- Recipe visibility fix
- Single kitchen [E] prompt
- POS/storage/station-radius fixes

## New restaurant creation fields

`/moccreate` now asks for:
- Restaurant Name
- Job Name
- Restaurant Type
- Map Blip Sprite ID
- Map Blip Color ID
- Blip Scale

The blip position is saved at the creator's current location.

## Edit existing blip

`/mocrestaurant`
-> Edit Restaurant Blip
-> Select Restaurant

You can change:
- Sprite ID
- Color ID
- Scale
- Move blip to your current position
