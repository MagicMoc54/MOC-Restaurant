### V2.2.2_CLOCK_IN_FIX.md

# MOC Restaurant v2.2.2 - Clock In / Clock Out Fix

This fixes the Business Management clock-in system.

## Fixed
- Verifies the moc_employees database row was actually updated.
- Reads the employee record back and verifies the saved clock state.
- Synchronizes QBCore SetJobDuty when the player's current QBCore job matches
  the restaurant job.
- Sends a confirmed clock-state response to the client.
- Automatically refreshes Business Management after clocking in/out.
- The button changes from Clock In to Clock Out immediately after the confirmed
  server update.
- Adds server-console diagnostics if a database clock update fails.

## Expected flow
Business Management
-> Clock In
-> success notification
-> menu refreshes
-> button now says Clock Out

Then:
Clock Out
-> success notification
-> menu refreshes
-> button says Clock In

No SQL update is required from v2.2.1 to v2.2.2.

### V2.2.3_DELIVERY_CALLBACK_FIX.md

# MOC Restaurant v2.2.3 - Delivery Callback Fix

This fixes:
`callback 'moc_restaurant:getDeliveryCatalog' does not exist`

## What changed
- Delivery server module moved to a fresh `server/deliveries_core.lua` file.
- Manifest explicitly loads the new module.
- Server prints when the delivery module begins loading.
- Server prints when delivery callbacks are registered.
- Client now catches a missing callback and shows a readable notification instead
  of throwing an ox_lib NUI callback error.

## After restart, txAdmin console should show
[MOC Restaurant] Loading v2.2.3 delivery server module...
[MOC Restaurant] Registering delivery callbacks...
[MOC Restaurant] Delivery callbacks registered: getDeliveryCatalog + getRestaurantDeliveries
[MOC Restaurant] v2.2.3 Deliveries & Restocking loaded.
[MOC Restaurant] v2.2.3 delivery diagnostics loaded.

No additional SQL is required from v2.2.2 to v2.2.3.
