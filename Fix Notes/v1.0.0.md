# MOC Restaurant

MOC Restaurant is a QBCore restaurant framework foundation for FiveM.

## Current Version
1.0.0 Core Foundation

## Requirements
- qb-core
- oxmysql
- ox_lib

Optional / planned bridge support:
- ox_inventory
- qb-inventory
- ox_target
- qb-target

## Installation
1. Place the `moc_restaurant` folder in your server resources folder.
2. Import `sql/moc_restaurant.sql` into your FiveM database.
3. Add these resources to your server.cfg in an appropriate order:

   ensure oxmysql
   ensure ox_lib
   ensure qb-core
   ensure moc_restaurant

4. Restart the server.
5. Use `/moccreate` as a QBCore admin to create a basic restaurant record.

## Notes
This is the Core/Foundation release. The in-game station placement builder,
menus, recipes, checkout, kitchen systems, food handoff animations, storage,
drive-thru, and management UI are planned for the next development stages.

## Upgrade Guidance

This release should be installed over the previous MOC Restaurant version in the release sequence. Review the `sql/` folder inside the resource for any SQL upgrade file associated with v1.0.0.
