# MOC Restaurant

## Version 1.1.0 - In-Game Builder

This development build adds the first usable restaurant location builder.

### Requirements
- qb-core
- oxmysql
- ox_lib

### Optional / Planned Bridges
- ox_inventory
- qb-inventory
- ox_target
- qb-target

## Installation
1. Place `moc_restaurant` in your resources folder.
2. Import `sql/moc_restaurant.sql` if you have not already imported the v1.0 schema.
3. Ensure dependencies before MOC Restaurant:

   ensure oxmysql
   ensure ox_lib
   ensure qb-core
   ensure moc_restaurant

4. Restart the server.

## Commands
- `/moccreate` - create a restaurant database record.
- `/mocbuilder` - select a restaurant and open the in-game location builder.

Both commands require the QBCore permission configured in `Config.AdminPermission`.

## Builder Workflow
1. Run `/moccreate`.
2. Create your restaurant.
3. Run `/mocbuilder`.
4. Select the restaurant.
5. Choose `Place Location`.
6. Stand where the station should be.
7. Choose the station type and confirm.
8. Repeat for registers, grill, fryer, storage, drive-thru points, etc.

The coordinates and heading are saved directly into the SQL database.

## Current Builder Location Types
- Register
- Grill
- Fryer
- Prep Station
- Drink Station
- Dry Storage
- Freezer
- Tray Pickup
- Manager Station
- Drive-Thru Speaker
- Drive-Thru Payment Window
- Drive-Thru Pickup Window

## Important
Version 1.1 is still a development milestone. These saved points are not yet full
interactive cooking/register stations. The next stage will connect the stored
points to actual target interactions and begin the register/menu/order system.

## Upgrade Guidance

This release should be installed over the previous MOC Restaurant version in the release sequence. Review the `sql/` folder inside the resource for any SQL upgrade file associated with v1.1.0.
